# as-qualibrate

`quam_libs`, the QuAM components and helpers (components, macros, dataset
helpers) of Quantum Machines' qua-libs superconducting examples, packaged on
its own so that it installs quickly on any operating system:

```bash
python -m pip install "as-qualibrate @ git+https://github.com/junyeeeeeeeeee/as-qualibrate.git@v0.1.0"
```

The JY agent's client installs it through its `qm` extra. The code is an
unchanged copy; changes belong upstream or in the code that uses it.
